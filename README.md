# Bulletin Board Application (Доска объявлений)

Полнофункциональное веб-приложение "Доска объявлений", разработанное на фреймворке Django.

## 🛠 Технологический стек:
- Python, Django Web Framework
- СУБД: SQLite / PostgreSQL
- Фронтенд-компоненты: Django Templates, HTML5, CSS3

## 🚀 Функционал:
- Публикация, редактирование и удаление объявлений пользователями.
- Категоризация объявлений с фильтрацией и возможностью полнотекстового поиска.
- Реляционная структура базы данных (связи один-ко-многим между пользователями, категориями и объявлениями).
